# 双色球模拟摇奖机（SSQ Lottery Simulator）

基于 **2003 年至今全部开奖数据**（3507 期）的网页版双色球模拟摇奖与流派分析工具。单文件 HTML，双击即用，也可在线访问。

> ⚠️ 本工具仅供娱乐与数据分析参考。双色球每期开奖为独立随机事件，任何历史统计都无法提高中奖概率，请理性购彩、量力而行。

---

## 功能特性

- **真实摇奖动画**：33 颗红球 + 16 颗蓝球双滚筒滚动出号，动画可减少动态效果（系统"减弱动态效果"设置）
- **8 大流派即时分析**：冷热频次 / 和值 / 奇偶 / 三区分布 / 连号 / 重号 / 蓝球形态 / 组合历史，每次摇奖基于最新数据实时计算
- **历史号码浏览**：3507 期全量数据分页查看（50/100/200 条每页），最新一期高亮，附奇偶·三区·和值简评
- **三种数据源**：内嵌数据（开箱即用）/ 本地文件（`从文件更新`按钮选择 JSON）/ 在线地址（GitHub raw，自动定时同步）
- **云端自动更新**：通过 GitHub Actions 定时抓取中国福彩网官方开奖接口，数据全程自动维护

## 文件结构

## 快速开始

### 方式一：在线使用（推荐）

1. 在仓库 **Settings → Pages** 启用 GitHub Pages（Branch: `main`, /root）
2. 等待约 2 分钟，访问 `https://<用户名>.github.io/SSQ-Lottery-Simulator/`（HTML 需命名为 `index.html` 时首页直接可用）
3. 打开后到"历史号码 → 数据源设置"，填入下方数据源地址，即可享受自动更新

### 方式二：本地使用

1. 下载 `双色球模拟摇奖机.html`，双击用浏览器打开
2. 内嵌数据已含全量历史（截至部署时最新一期），可直接摇奖、分析、浏览历史
3. 需要更新数据时，点击"从文件更新"选择最新的 `ssq_data.json`

## 数据源设置

打开程序 → 历史号码 → **数据源设置**，粘贴本仓库的 raw 链接：

```
https://raw.githubusercontent.com/<用户名>/SSQ-Lottery-Simulator/main/ssq_data.json
```

（默认分支为 `master` 时，将 `main` 改为 `master`）

设置后程序行为：

- 打开页面时自动拉取一次
- 每 5 分钟自动检测，发现新数据立即刷新（全部统计同步重算）
- "手动更新"按钮随时强制拉取
- 更新优先级：在线地址 > 本地文件 > 内嵌数据

## 数据自动更新机制

1. 每期开奖（周二 / 周四 / 周日 21:15 左右）后，`ssq-update.yml` 定时任务在开奖日 21:15–23:00 每 15 分钟检查一次
2. `fetch_ssq.py` 调用中国福彩网官方开奖接口（服务端抓取，无跨域限制）
3. 发现新期 → 自动合并进 `ssq_data.json` 并提交；无新期 → 静默退出（不产生空提交）
4. 所有使用者在 5 分钟内自动同步，全程无需人工干预

可在仓库 **Actions** 页面手动点击 **Run workflow** 立即触发一次更新。

## 数据说明

- 数据来源：中国福彩网官方开奖公告，交叉核对
- 覆盖范围：2003 年第 2003001 期至当前最新一期
- 字段：期号 | 开奖日期 | 红球 1-6 | 蓝球
- 如某期偶发漏抓，脚本每次会拉取最近 12 期并自动补全中间遗漏
